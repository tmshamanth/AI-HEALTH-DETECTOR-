# 🩺 AI Disease Detection System

## 📌 Overview

The **AI Disease Detection System** is a Machine Learning-based desktop application that predicts the most likely disease based on symptoms selected by the user. The application is designed to demonstrate how Artificial Intelligence can assist in preliminary disease prediction using a trained classification model.

This project provides a modern graphical user interface (GUI) where users can enter symptoms, receive disease predictions, view confidence scores, and maintain a prediction history. It is developed for learning purposes and showcases the integration of Machine Learning, GUI development, and database management in a real-world application.

# 🤖 Machine Learning Algorithm

The project uses the **Random Forest Classifier** for disease prediction.

The model is trained using a symptom dataset where each symptom is represented as a feature. During prediction, the selected symptoms are converted into numerical values and passed to the trained model. The algorithm analyzes the symptom patterns and predicts the most probable disease.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/AI-Disease-Detection-System.git
```

Go to project folder

```bash
cd AI-Disease-Detection-System
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

---

# 📷 How to Use

1. Open the application.
2. Select or enter the symptoms.
3. Click the **Predict Disease** button.
4. View the predicted disease and confidence score.
5. Check the Prediction History page to view previous records.
6. Use the Clear History option if needed.
